How to use this dashboard
  • Use the search box to find a gene (for example PIK3CA) or a disease (for example lymphatic malformation).
  • Use the filter to show only one evidence strength, or only minimal or optional regions.
  • Click a row to see the full record and its references. Click a gene name to see its variants, exons and regions of interest.
  • Switch between the two tabs to move between the tables.
  • Use Export CSV to download the rows currently shown.
